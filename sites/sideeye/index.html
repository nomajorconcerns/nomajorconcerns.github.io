In development · not released

Every agent gets the side-eye.

Knows what normal looks like. Notices when it isn't.

SideEye is agent detection and response for AI agents. The goal is to learn what is normal for each agent on your computer, flag what is not, and contain the agent. It is meant to sit beside Cephalo, which blocks dangerous tool calls before they run, but neither requires the other.

What exists today. A desktop console (Windows build tested) running on sample data, and a read-only live view of Cephalo's audit log. Per-agent baselines, anomaly flags and containment are Planned, not built. Nothing is downloadable yet.

Network, telemetry, updates

  • The app has no HTTP client among its Rust dependencies and no fetch call in its interface code.
  • Its content-security policy allows connections only to itself.
  • There is no telemetry and no updater. The only socket it opens is the loopback one above, and only in Enforce mode.

Honest limits

What SideEye does, and what it does not.

AreaSideEye doesSideEye does not
TodayBuilt Shows a console on sample data, and a live read-only view of Cephalo's audit log.Detect anything on its own. Every alert and agent in the console is sample data.
What it can seeBuilt Reads what Cephalo logs for Claude Code and Hermes.See an agent Cephalo does not hook, or anything Cephalo does not log.
Warm-upPlanned Learn what is normal for each agent from its history.Say anything useful in the first days. A new baseline is wide, and a flag from it means little.
False positivesPlanned Flag behaviour that is unusual for that agent, with a plain-English reason.Tell new work from new danger. A legitimate one-off job will be flagged too. You mark those as expected.
Detection, not preventionPlanned Notice after an action, and contain the agent.Stop the first bad action. Blocking before a call runs is Cephalo's job, and it only blocks what its rules match.
Same-user tamperRuns as you, like the agents.Protect itself from something running as the same user. That includes the agent: it could stop SideEye or edit its files. Tamper protection is Planned. Real isolation needs another OS user or a container.
Approving Cephalo's holdsBuilt In Enforce mode, shows a pop-up for an action Cephalo would ask about (Claude Code only). Allow once, or Block. No answer in 40 s means block.Work yet for most people. It needs a change to Cephalo that has not shipped, and no "Always allow" exists for real holds.
ScopeRuns as an ordinary app on your machine.Act as a sandbox, run kernel code, read prompts or capture the screen.

Install

Not installable yet.

There is no download, no package and no install command. A Windows installer exists, built locally and unsigned, and it is not published.

  • Planned Signed Windows .msi, macOS .dmg, and Linux .deb, .rpm and AppImage.
  • Planned Signed, staged updates with rollback.
  • Planned Start at login stays off by default.

With Cephalo

Cephalo blocks before. SideEye is meant to watch after.

Cephalo checks each tool call against your rules and blocks the dangerous ones before they run. It is released. SideEye does not need it, and Cephalo does not need SideEye. Today the two share only a read-only view of Cephalo's log and the approval pop-up above.

Limit: the pop-up needs a Cephalo change that is not shipped, so nothing connects them for most people yet.
