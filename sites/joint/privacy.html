Privacy

This site collects nothing. Here is exactly what it does and does not do.

What the site does not do

  • It sets no cookies.
  • It runs no analytics and no visit counter.
  • It loads nothing from other hosts: no font services, no CDNs, no trackers. Fonts, styles and scripts are served from this site.
  • It has no forms and sends nothing anywhere.

What stays in your browser

If you use the page settings or the install checklist, your browser's local storage keeps a few small values so the page remembers them next time. They never leave your device.

  • nmc.theme: dark or light, if you chose one.
  • nmc.motion: whether you turned motion off.
  • nmc.facts: whether "Just the facts" is on.
  • nmc.install: which install steps you ticked.

Clearing site data for this page removes them.

Hosting

The site is static files served by GitHub Pages, which keeps its own server logs. See GitHub's privacy statement. We do not receive those logs.

The products

This page covers the website only. For what each product collects and stores, see the Cephalo site and the SideEye site.
