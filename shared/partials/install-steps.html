1. Node.js 20 or newer. You also need Claude Code, Hermes, or both.

    node --version

  2. One command, the same on every system.

    npm install -g @nomajorconcerns/cephalo

    Then cephalo --help should show the banner and command list.

  3. It prints a plan first, asks before changing anything, creates ~/.cephalo/rules.yml from the defaults, and adds its hook to Claude Code and (if found) Hermes. Every file it edits is backed up to <file>.cephalo-backup-<timestamp>.

    cephalo init

  4. Claude Code reads hooks when it starts, so a running session will not pick up the new hook.

  5. Hermes skips a hook command until you approve it once. Start an interactive hermes, accept the prompt, then check the list. It should say allowed, not not allowed.

    hermes hooks list
hermes hooks doctor

  6. doctor checks the rules file, runs a self-test and confirms the hooks. Then prove a block, and watch decisions arrive live.

    cephalo doctor
cephalo test "DROP TABLE users"
cephalo watch
